# geoguessr-location-predictor
An AI-assisted desktop application for predicting geographic locations from image scenery.

## 🌟 Key Features
* **Scenery Image Analysis:** Predicts precise geographical targets using image recognition principles.
* **Interactive Desktop GUI:** Built with `PyQt5` for a responsive and user-friendly experience.
* **Rapid Prototyping:** Integrated open-source AI image classification workflows for real-time location inference.

## 🛠️ Tech Stack & Tools
* **Language:** Python
* **GUI Framework:** PyQt5
* **Libraries & Concepts:** Image Preprocessing (`Pillow`), Open-Source AI Vision Workflows, Rapid Prototyping
